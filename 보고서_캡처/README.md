## 5번 캡션 안내

- `05_review.png`는 장점·보완점 예시가 아니라 **인용 검증 기능**을 보여 주는 화면으로 씁니다.
  - 권장 캡션: "원문 인용이 확인되지 않은 피드백은 자동으로 보류하는 인용 검증 기능"
  - 화면의 좋은 점·보완할 점은 모두 "원문 인용을 확인할 수 없어 이 항목의 평가를 보류했습니다"로 나옵니다.
  - qwen3.5:9b로 두 조합(운영·예산 + 01 pptx, 기술 검토 + 02 pdf)을 시도했고 결과가 같았습니다.

- 브라우저 가로 1440px, 개인 정보가 없는 테스트 계정으로 찍었습니다.
